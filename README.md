# QuickInfo

QuickInfo is an NVDA add-on that provides quick, on-demand announcements of useful
system and NVDA-related information that is not easily available elsewhere.

The add-on is designed to be lightweight, reliable, and safe. All commands are
read-only and do not change system or NVDA settings.

## Features

QuickInfo can announce:

- Availability of Screen Curtain (informational only)
- Caps Lock and Num Lock state
- Current keyboard layout
- NVDA cursor context (focus and review)
- Connected Wi-Fi network name
- Network connection type (Wi-Fi or Ethernet)
- Active audio output device
- Clipboard content type (text or files)

## Default keyboard shortcuts

- NVDA+Ctrl+Shift+F9: Screen Curtain information
- NVDA+Ctrl+Shift+F7: Caps Lock and Num Lock status
- NVDA+Ctrl+Shift+K: Keyboard layout
- NVDA+Ctrl+Shift+C: NVDA cursor context
- NVDA+Ctrl+Shift+F10: Wi-Fi information
- NVDA+Ctrl+Shift+N: Network connection type
- NVDA+Ctrl+Shift+F6: Audio output device
- NVDA+Ctrl+Shift+V: Clipboard content type

## Customizing shortcuts

QuickInfo provides default shortcuts for all commands.

To change a shortcut:
1. Open NVDA → Preferences → Input Gestures
2. Choose Add
3. When prompted, press the existing QuickInfo shortcut
4. Assign a new gesture

## Compatibility

- Windows 10 and later
- NVDA 2024.1 or later
